Private Sub ultraGridERPPurchaseOrders_InitializeRow(sender As Object, e As Infragistics.Win.UltraWinGrid.InitializeRowEventArgs) Handles ultraGridERPPurchaseOrders.InitializeRow

        Dim row = e.Row
        row.Selected = False
        If row.Band.Index = 0 Then
            Dim PoLine = TryCast(row.ListObject, QuickReportSchema)
            If (PoLine.FinessePart Is Nothing) Then
                If (PoLine.Disassemblies Is Nothing OrElse PoLine.Disassemblies.Count = 0) Then
                    row.ToolTipText = "This part does not exist in Finesse, and no subparts have been added. Please create the part or add the required subparts."
                End If
                row.Appearance.BackColor = ColorPalette.DangerRow
            End If

            If (row.HasChild) Then
                row.ToolTipText = "This PO Line contains Subparts. Please receive all the subparts."
                row.Appearance.BackColor = ColorPalette.GrayRow
            End If
        End If

    End Sub
